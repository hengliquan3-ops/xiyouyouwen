西邮有问 迁移包

一、新电脑需要什么
只安装 Python 3（建议 3.10 以上），不需要 Node、数据库或其他依赖。

二、启动
Windows：解压后双击 start.bat。
macOS / Linux：在文件夹里运行 bash start.sh。
如果解压后脚本没有执行权限，用 bash start.sh 就可以，不需要改权限。

三、打开
学生端：http://127.0.0.1:8000/
管理端：http://127.0.0.1:8001/admin

管理密钥沿用旧电脑设置的那个，不需要重新设置。如果忘记了，可以删除 data/admin.json 后重启，再重新设置。
AI 密钥保存在 .env，目前为空；登录管理端后可在“AI 设置”里填写。

四、数据在哪里
data/materials.json     学校资料
data/notices.json       校园通知
data/products.json      集市商品
data/conversations.json 私聊会话
data/messages.json      私聊消息
data/reports.json       举报
data/admin.json         管理密钥（加密保存）
data/ppt、data/uploads  课件和商品图片
.env                    AI 密钥与运行配置

五、公网访问
公网隧道绑定的是原来那台电脑。迁移后需要在新电脑重新运行 start-public.sh，会生成新的公网地址。
Windows 运行 start-public.sh 需要 WSL 或 Git Bash，并且能使用 ssh；只做本地开发时不需要这一步。
只想本地开发时，不需要启动公网隧道。

六、注意
1. 这个压缩包包含管理密钥和现有聊天/商品数据，不要上传到公开网盘或群聊。
2. 复制到新电脑后，两台电脑的数据不会自动同步；请选一台作为主电脑继续开发。
3. AI 密钥如果以后填过，传输 .env 时也要按敏感文件处理，不要发到聊天里。
4. 旧电脑的免费公网地址在关机后会失效，迁移后使用新生成的地址。
